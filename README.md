**Memmorizes** est une plateforme de prise de notes et d'apprentissage spécialisée, conçue pour aider les étudiants de tous niveaux à maîtriser de nouvelles matières. Grâce à son assistant IA propulsé par **Google Gemini**, Memmorizes transforme la manière de réviser en générant des fiches de révision sur-mesure, en suivant la progression de manière détaillée et en centralisant les ressources utiles.



## ✨ Fonctionnalités Clés

-   🧠 **Parcours d'Apprentissage Personnalisé** : Définissez votre niveau (de Débutant à Expert) pour adapter le contenu à vos connaissances.
-   🤖 **Fiches de Révision par IA** : Générez en quelques secondes des fiches claires et concises sur n'importe quel sujet grâce à l'API Gemini.
-   📊 **Suivi de Progression Détaillé** : Marquez les sujets comme "Non commencé", "En cours", "Terminé" ou "Maîtrisé" et visualisez votre avancement sur le dashboard.
-   📈 **Dashboard Interactif** : Obtenez une vue d'ensemble de votre progression hebdomadaire (XP), de votre niveau et de votre maîtrise globale par matière.
-   📁 **Gestion de Documents** : Uploadez, prévisualisez et gérez vos propres documents de cours (PDF, images, textes) directement dans l'application.
-   🛠️ **Boîte à Outils & Ressources** : Accédez à une sélection d'outils (Figma, Excalidraw...) et de ressources d'aide pour la vie étudiante.
-   🌓 **Thème Clair & Sombre** : Basculez entre les thèmes pour un confort visuel optimal à toute heure de la journée.

## 🛠️ Stack Technique

Ce projet a été construit avec des technologies modernes, performantes et axées sur l'expérience développeur.

-   **Frontend** : [React](https://reactjs.org/) & [TypeScript](https://www.typescriptlang.org/) pour une application robuste, typée et scalable.
-   **Styling** : [TailwindCSS](https://tailwindcss.com/) pour un design system utility-first rapide et élégant.
-   **Intelligence Artificielle** : [Google Gemini API (@google/genai)](https://ai.google.dev/) pour la génération de contenu intelligent.
-   **Stockage Côté Client** : [IndexedDB](https://developer.mozilla.org/fr/docs/Web/API/IndexedDB_API) pour une persistance des documents de l'utilisateur en mode hors-ligne.
-   **Graphiques** : [Recharts](https://recharts.org/) pour la visualisation des données de progression.

## 🚀 Démarrage Rapide

Pour lancer ce projet en local, suivez ces étapes :

1.  **Clonez le dépôt**
    ```bash
    git clone https://github.com/votre-username/memmorizes.git
    cd memorizes
    ```

2.  **Installez les dépendances**
    *Le projet est configuré pour fonctionner dans un environnement comme AI Studio et ne nécessite pas d'installation de dépendances locale.*

3.  **Configurez les variables d'environnement**
    Assurez-vous d'avoir une clé d'API pour Google Gemini. L'application est configurée pour la lire depuis `process.env.API_KEY`.

4.  **Lancez l'application**
    Ouvrez le fichier `index.html` dans votre navigateur ou servez-le via un serveur local.
